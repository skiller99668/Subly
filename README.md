# Subly
Student subleases & roommates, on a map — find a place, a roommate, or a safe spot near campus, anywhere. Free to post.

## Getting Started

### Prerequisites
- Node.js 18+ installed
- A free Mapbox account (get one at https://www.mapbox.com/)
- A free Supabase project (get one at https://supabase.com/)

### Setup

1. **Clone or navigate to the project**
   ```bash
   cd c:\Users\skyle\Projects\Subly
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Get your Mapbox token**
   - Go to https://account.mapbox.com/
   - Sign up for a free account (if you don't have one)
   - Navigate to "Tokens" in the left sidebar
   - Copy your default public token

4. **Create `.env.local` file** in the project root:
   ```bash
   cp .env.example .env.local
   ```
   Then fill in your Mapbox token and your Supabase project URL, anon key, and
   service role key (Supabase Dashboard → Project Settings → API).

5. **Set up the database**

   Paste the contents of [`database.sql`](database.sql) into the Supabase SQL
   editor (Dashboard → SQL Editor → New query) and run it. It creates every
   table, row-level-security policy, notification trigger, and the
   `listing-images` storage bucket.

   The file is idempotent — re-run it any time to pick up schema changes
   without losing data. `scripts/setup-db.py` applies it over a direct Postgres
   connection if you'd rather not use the dashboard.

6. **Run the development server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## Current Features
- ✅ Interactive Mapbox map that spawns at the signed-in user's location
- ✅ Real listings with photos, clustered as price pins on the map
- ✅ Map view or list view, with a grid/list layout toggle
- ✅ Post / edit / delete your own listings, with image upload
- ✅ Student attribute tags (roommate, women-only, students-welcome, furnished, …) with a category filter bar
- ✅ Price / size / move-in date / proximity filters and sorting
- ✅ Location search that scopes the map and the list to a searched area
- ✅ Favorites & saved listings
- ✅ Direct messaging between users, with unread counts
- ✅ Comment threads on listings
- ✅ Star ratings + written reviews, both for hosts/landlords and for properties
- ✅ Notifications for messages, comments, reviews, and saves on your listings
- ✅ Email/password and Google sign-in, with email verification

## Architecture
- **Frontend**: Next.js (App Router) + React + TypeScript
- **Styling**: Tailwind CSS
- **Mapping**: Mapbox GL + react-map-gl, clustering via supercluster
- **Database**: Supabase (PostgreSQL) with row-level security on every table
- **Auth**: Supabase Auth (credentials + Google OAuth)
- **Storage**: Supabase Storage (`listing-images` bucket, one folder per user)

Notifications are generated by database triggers rather than in API routes, so
they also fire for writes the browser makes directly to Supabase (favoriting,
for instance). See the trigger section of [`database.sql`](database.sql).
